# RootOut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship RootOut v1.0.0 — a minimal Liquid Glass macOS deep app uninstaller — as a DMG on GitHub Releases.

**Architecture:** Swift Package with a unit-tested `RootOutCore` library (inventory, scanner, uninstaller) and a `RootOut` SwiftUI executable; shell scripts assemble the `.app` bundle and DMG. No Xcode project file.

**Tech Stack:** Swift 6 / SwiftUI, swift-tools 6.0, `swift test`, `hdiutil`, `codesign` (ad-hoc), `gh` CLI.

## Global Constraints

- App name: `RootOut`; bundle ID `com.tonmoybishwas.rootout`
- arm64 only; min deployment macOS 15.0; `.glassEffect()` behind `#available(macOS 26.0, *)` with `.ultraThinMaterial` fallback
- Never touch `com.apple.*` bundle IDs, `/System/**`, or RootOut itself
- Deletions go to Trash via `FileManager.trashItem`; admin fallback only for explicitly confirmed root-owned paths
- No network access, no telemetry, no third-party dependencies
- MIT license; repo `https://github.com/TonmoyBishwas/RootOut-mac.git`

### Task 3: LeftoverScanner

**Files:**
- Create: `Sources/RootOutCore/LeftoverScanner.swift`
- Test: `Tests/RootOutCoreTests/ScannerTests.swift`

**Interfaces:**
- Produces: `struct LeftoverScanner { init(userLibrary: URL, localLibrary: URL); init() /* real ~/Library and /Library */; func scan(app: InstalledApp) -> [LeftoverItem] }`
- Matching rules: (a) exact bundle-ID match on file/dir base name (e.g. `com.foo.Bar`, `com.foo.Bar.plist`, `com.foo.Bar.savedState`); (b) bundle-ID prefix match for launch items (`com.foo.Bar.agent.plist`); (c) app-name exact directory-name match (case-insensitive) only in `Application Support`, `Caches`, `Logs`, and only when name length ≥ 4 and not in a common-word denylist (`{"app","mac","pro","lite","beta","test","tools","player","editor","music","notes","mail","photos"}`).
- Locations scanned (relative to each Library): `Application Support`, `Caches`, `Preferences`, `Containers`, `Group Containers`, `Saved Application State`, `Logs`, `LaunchAgents`, `LaunchDaemons` (local only), `HTTPStorages`, `WebKit`, `Cookies`, `Application Scripts`, `Logs/DiagnosticReports` (prefix match on app name for `.ips`)
- Result always includes the `.app` bundle itself as `LeftoverKind.app`, first.

Tests:
- [ ] finds bundle-ID-named dirs/files across fixture locations, correct kinds
- [ ] negative: app "Notion" does NOT match dir "Notes"; "Slack" doesn't match "SlackFixPro" (exact-name rule)
- [ ] denylist: app literally named "Notes" (non-Apple) does not name-match `Application Support/Notes`
- [ ] never returns paths outside the whitelisted location roots
- [ ] never matches inside another bundle ID's `Containers` dir
- [ ] Implement, green, commit "feat: leftover scanner"

**Interfaces:**

Tests:

- [ ] nonexistent path → failed entry, no throw
- [ ] unsafe path (e.g. `/usr/bin/x`) → failed "unsafe path", untouched

- [ ] Implement, green, commit "feat: uninstaller and size calculator"
